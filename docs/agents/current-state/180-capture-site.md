# Capture Site

Built for starter sites, removed-site restoration, the Page patterns review, Capture Site for unknown sites (`brwr-t40`), Improve with AI (`brwr-f45`, a `site_draft` service run judged by the host), and an automatic persistent headless review task after each successful Capture Site save, with compact progress, a Tasks link and host-validated additive rule updates
Configured sites offer an inline Remove site review in the panel that stops future capture while keeping saved notes, summaries and history.
