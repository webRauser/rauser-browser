## 2026-11-23 — Brauser Stash

Stash replaced the deferred Read later design with a sidebar save button and a dedicated tab using Artifact Explorer styles.
The selected home keeps one source receipt per host-derived record key.
An existing owned summary is reused, and the usual summary queue handles missing summaries.
A separate completion receipt keeps both the saved source and its summary available after Mark done.
The tab exposes title and source search, To read, Done and All views, and source and summary actions.
